Running text and margin notes

Body text sits on a fixed measure of about sixty-six characters, which is the width at which the eye finds the start of the next line without hunting for it. The column to the right is not empty space — it holds notes, set beside the paragraph they belong to rather than at the foot of the page.

This is a margin note. On a wide screen it sits out here; on a phone it folds into the text as an indented block with an accent rule. Use it for the aside that would otherwise interrupt the sentence.

That convention comes from Edward Tufte, and it is the one piece of this design worth keeping if you change everything else: a reader can take the aside without losing their place, which a footnote never allows.

Tables

Figures are set in a monospaced face with tabular numerals, so digits line up in columns whatever their value. A table wider than the measure scrolls inside its own container rather than pushing the page sideways.

Code

Code blocks scroll horizontally on their own so that a long line never widens the page: 

library(bvarsv)

fit <- bvar.sv.tvp(Y, p = 2, nrep = 50000, nburn = 5000)
impulse.responses(fit, impulse.variable = 1, response.variable = 2)

Lists

  • Ordinary bulleted list.
  • Set on the same measure as the running text.
  • Numbered lists work the same way.

That is everything the stylesheet provides. Anything else you write will inherit the body type and the measure without further work.
